> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AX 最大サイズの検証撮影を exit=0 で全シーン撮れるようにし (#261)、記録タブのタスク一覧とバッジを AX で実測してから直し (#260)、チュートリアルの「記録する」の帯を AX のときだけ自動スクロール・列いっぱいにして表示条件を 1 つの helper にまとめる (#262)。1 ブランチ・1 PR (`feat/ax-polish-260-262`) で 3 issue を close する。

**Architecture:** 撮影テスト (`VerificationScreenshotUITests`) に「ボタンが見つかるまでスクロールする」helper を足し、記録タブのタスク一覧シーンを追加する。アプリ側の AX 分岐は #259 と同じく **static pure helper + unit test** で判定を固定し、`@Environment(\.dynamicTypeSize)` の配線は撮影で確かめる。自動スクロールは `TutorialStepContainer` 全体を `ScrollViewReader` で包み、`scrollTarget` が変わったら `proxy.scrollTo` する。

**Spec:** GitHub Issue #261 / #260 / #262 の本文とコメント (2026-10-17 起票、#253 / PR #259 から切り出し)。2026-10-18 triage の user 判断: (1) 3 件を 1 PR、(2) #262 の自動スクロールは **AX のときだけ** 入れる (効かなければ入れずに報告)、(3) #260 のバッジの直し方は **実測の後に user が決める**。

- push・PR 作成はこの plan の範囲外 (finishing-a-development-branch で行う)
